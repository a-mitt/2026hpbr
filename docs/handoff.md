## 7. マップ（今回の主な作業）

素材：`public/assets/map/`（すべて 1920×1080 の透明PNG。`wallonly`＝背景、`stairs`、家具9枚、`toiletdoor`、`goal`＝完成形の見本）。元データはユーザーのPCの `OneDrive\画像\自分の絵\map_parts`。

- **カメラ**：常にキャラが画面中央（遅れなし）。マップの端では外側の黒が見える。画面は960×540のままで、マップ（1920×1080）は等倍。
- **キャラ**：見た目を1.7倍（`CHARACTER_SCALE`）。中心から足元まで `FOOT_OFFSET`（61px）。**当たり判定・前後（depth）はすべて足元の点**で決める。NPCの `npcs.json` の `x,y` は「キャラ中心」（足元＝y+61）。
- **データは `src/data/mapLayout.js` に集約**：歩ける範囲 `WALKABLE`、通れない範囲 `BLOCKED`（家具の「足元」だけ。天板の下やソファの後ろは通れる）、部屋 `ROOMS`、家具の `sortY`、トイレのドア `TOILET_DOOR`、階段の扉 `EXIT_DOOR`、開始位置 `PLAYER_START`。値は画像から読んだ**概算**で、実際に歩いて調整が必要。
- **家具の前後**：キャラの足元が家具の `sortY` より上にいると家具が手前に描かれ、後ろに回り込んだように見える（デスク・マッサージ台・ソファ・小さなテーブル・ロングソファ・棚・テレビ）。
- **部屋の暗さ**：階段／玄関・キッチン・トイレ／メイン／奥の部屋の4つ。いない部屋は黒の乗算レイヤー（`DARK_ALPHA` 0.7）で暗くなり、入ると0.35秒で明るくなる。階段エリアは通れないので常に暗い。
- **トイレのドア**：外（足元がドアの前）で Space/Enter かクリックで開閉。開けると便器の手前に入れる。中にいる間は閉められない。ドア画像自体に暗い半透明面がある。
- **階段の扉**（絵なし）：玄関と階段の間。近づくと「!」→ Space/Enter かクリックで `ExitPromptScene`（「終わりにして帰る？」もう少し／帰る／1人で残る）。「帰る」は「エンディングは準備中です」。「1人で残る」は全コレクション達成まで薄字で、押すと「まだ全てのコレクションを達成していません」。達成判定は `src/systems/progress.js`（**今は常にfalseの仮実装**）。
- **NPC（7人）**：トメ・律・ショウ・モブ・エクボ・テル・芹沢。台詞は全員「セリフ準備中」。位置はエクボ＝デスク右の壁際、テル＝キッチン前、ほかは仮。

## 10. 作業環境メモ

- ユーザーはPythonが主言語。JSの説明には必要に応じてPythonの書き方を一言添える。説明は簡潔に。
- 進め方：計画→ユーザーが「OK」→最後まで自動実行。**3回自己修正に失敗したら止めて報告**（`CLAUDE.md`）。
- **開発用のURL**（`npm run dev` のときだけ有効。本番ビルドでは無効）：`http://localhost:5173/2026hpbr/?scene=FieldScene&px=1000&py=700&debug=1&panel=settings` など。`px,py`＝プレイヤーの足元でなく中心座標、`debug=1`＝F2表示を最初からON、`panel=settings|library|terms|credits`、`exit=1`＝終わりの選択を表示。F2キーで当たり判定・部屋・完成形の重ね絵を表示。
- 画面確認：PCは `chrome.exe --headless --screenshot=... --window-size=960,540 --virtual-time-budget=8000 "<dev URL>"` で撮影した。クラウドは `npm run build` → `npx vite preview` ＋ Playwright。
- このツール経由のPython（heredoc）では、文字列中の `\n` が実際の改行に変わってしまうことがある。JSの文字列に `\n` を入れるときは Edit ツールで直接書く。
- PCでは fontTools の一部（CFF）が企業ポリシーで動かないことがある（無心の字数を確認できなかった）。
- クラウド環境はフォント配布サイトや acrobat.adobe.com に接続できない。素材は `public/assets/` か `docs/` に置いてpushしてもらう。
- PC側で `npm install` すると `package-lock.json` が変わることがある。意図した依存追加でなければ戻す。
- 改行コード：Windowsで「LF will be replaced by CRLF」の警告が出る。無視してよい。
