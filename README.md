## 起動方法

プロジェクトフォルダ（`my-game`）で実行します。

```sh
npm install
npm run dev
```

表示されたURLをブラウザで開きます。通常は `http://localhost:5173/` です。

本番用ファイルの生成と確認：

```sh
npm run build
```

## ファイルの役割

- `index.html`：ブラウザページとゲーム表示領域。
- `src/main.js`：Phaserゲームの起動。
- `src/config.js`：画面サイズ、背景色、拡大縮小方法、最初のシーン。
- `src/constants.js`：表示窓・マップ全体のサイズとプレイヤー移動速度。
- `src/scenes/IntroScene.js`：作品説明・注意書き・同意画面。
- `src/scenes/BirthdayScene.js`：ろうそく点火からお祝い画面までの演出。
- `src/scenes/FieldScene.js`：部屋型の仮マップと登場オブジェクト。
- `src/objects/Player.js`：矢印/WASDで動かすプレイヤー。
- `src/objects/Npc.js`：番号付き仮NPCの表示。
- `src/data/npcs.js`：NPCの識別子・仮名・色・配置座標。
- `src/scenes/DialogScene.js`：名前枠、仮ポートレート、会話パネル。
- `src/systems/DialogManager.js`：タイプ表示や会話行の進行状態。
- `src/systems/CursorManager.js`：ろうそく・NPC・調べられる物に応じたカーソル表示。仮SVGを画像に差し替える場所。
- `src/data/npcs.json`：NPCの名前・位置・色・セリフ（`lines`）。正式な名前とセリフはここで編集。
- `src/data/dialogues.js`：`npcs.json` から会話データを作る読み込み用。通常は編集しない。
- `src/systems/DebugOverlay.js`：マップでF2キーを押すと、マウス座標・クリック範囲・歩ける範囲を表示する開発用の補助。
- `public/assets/`：素材置き場。`map/`（背景）、`npc/`（キャラ）、`items/`（調べる物）、`birthday/`（誕生日演出）、`ui/`（カーソルなど）。
- `package.json`：実行コマンドとPhaser/Vite依存関係。
- `package-lock.json`：インストールした依存関係の固定情報。
- `public/assets/`：後で画像などの素材を置く場所。

## 現在の状態

Phase 4完了。初期説明画面には作品概要、非公式表記、制作中の不具合に関する注意、制作者仮表記を表示します。「同意して始める」から誕生日演出へ進み、ろうそく点火とお祝いの後にクリックでマップへ移動します。表示窓は800×600、マップ全体は960×1200の縦長で、カメラがプレイヤーを追います。部屋型の仮マップに12人を縦方向へ配置し、矢印/WASD移動と室内境界を確認済みです。実背景を差し替える場合は960×1200、または同じ4:5比率の1920×2400を目安にします。NPCから60px以内の「！」、Space/Enterまたはクリックで始まる会話、30ms/字の仮セリフ表示も実装済みです。カーソルはろうそく上でマッチ、NPC上で会話、通常領域で標準表示に切り替わります。調査用オブジェクトには目カーソルを割り当てられます。正式な台詞は `src/data/dialogues.js`、カーソル画像は `src/systems/CursorManager.js` で差し替えます。Viteのビルド時にはPhaser本体のサイズ警告が出ますが、ビルドは成功します。
