# 誕生日お祝いミニRPG

誕生日をお祝いするための、ブラウザで遊べる小さなRPGです。マップを歩き回って、みんなと話したり、いろいろなものを調べたりします。

- 遊ぶ：<https://a-mitt.github.io/2026hpbr/>
- 推奨環境：最新版の Chrome / Safari / Edge（横画面推奨・スマホ可）
- 日本語 / English 対応
- 個人情報は取得しません。進み具合のみブラウザ内に保存します。

## 注意

- 二次創作（ファンゲーム）です。公式とは一切関係ありません。

## 操作

- 移動：矢印キー / WASD（スマホは画面上のスティック）
- 話す・調べる：Space / Enter、または対象をクリック / タップ
- 右上のボタンから、ライブラリ（集めたものの一覧）や設定を開けます。

## 開発者向け

Node.js が必要です。リポジトリのルート（`package.json` のある場所）で実行します。

```sh
npm install
npm run dev      # 開発サーバー（通常は http://localhost:5173/）
npm run build    # 本番用ファイルを dist/ に生成
```

使用技術：[Phaser 3](https://phaser.io/) + [Vite](https://vitejs.dev/)（JavaScript）。
`main` ブランチへの push で GitHub Actions が GitHub Pages にデプロイします。

### フォルダ構成

- `src/scenes/`：画面ごとの処理（導入、誕生日演出、マップ、HUD、会話、エンディングなど）
- `src/systems/`：会話・カーソル・ライブラリ・セーブ・多言語などの共通処理
- `src/objects/`：プレイヤーとキャラクター
- `src/data/`：マップの座標、キャラ、セリフ、オブジェクト、タスクなどのデータ
- `public/assets/`：画像・フォントなどの素材

マップ上で F2 キーを押すと、当たり判定などを確認できる開発用の表示が出ます。
